# Rollout Workspace `base_1`

## Trajectory Notes
# TRAJECTORY: base_1 (Initial Rollout)

1. Запущен базовый сбор котировок с MOEX ISS API (режим TQBR) и внутреннего JSON API СПБ Биржи (spbexchange.ru/api/reader/marketdata/default/rus).
2. Обнаружены две критические проблемы, требующие раздельного улучшения по осям INV (процедурная верификация и скрипты) и DOM (предметная финансовая методология):
   - Инженерно-процедурная проблема (INV): API СПБ Биржи отдаёт числа в виде строк с русской запятой ("173,9", "0,1021"), использует сертификат Минцифры РФ и альтернативные тикеры (TCSG вместо T), а при отсутствии автоматического верификатора целостности JSON-бандла возможен рассинхрон между расчётными таблицами и dashboard/data_bundle.js.
   - Предметно-методологическая проблема (DOM): При наивном расчёте EV/EBITDA и P/E по одноклассовой капитализации из TQBR возникают грубые искажения по привилегированным акциям TRNFP (21,45% уставного капитала) и двойным классам акций SNGS / SNGSP, а без коэффициента реализации выплат (payout_realization) обыкновенные акции SNGS ошибочно получают такой же балл, как привилегированные SNGSP.
